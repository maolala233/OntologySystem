# MVP 抽取流水线说明与平台结合方案（详细版）

> 基于 feat_simplify @ eb7f93d+（2026-11-17）；脚本 `test/outside_test/ontology-modeling-run/ontology_mvp.py`（独立可跑，不依赖平台代码改动）。
> 实测来自三类型验证：xlsx（普惠功能梳理）/ docx（科创e贷手册）/ pdf（信银理财 242 号说明书，33 页条款型）。
> 设计总原则：**LLM 只做声明与评审，代码做全部体力活**——输入规模绑「结构新颖度」，不绑文档体积。

---

## 〇、产出分层总览

构建一次，产出三层（职责严格分离）：

| 层 | 内容 | 存放位置 | 消费方 |
|---|---|---|---|
| **业务本体层** | 业务类/实例/关系/公理/SWRL/属性模板 | 本体图（画布/QA/Neo4j/行表） | 图谱可视化、问答、推理 |
| **文档结构层** | 条款号+条款原文+数值槽 | `card.doc_clauses` → spec_card.json | 溯源下钻、事后补抽、审计 |
| **溯源层** | 逐产物证据原文+来源文档+字符定位 | ProvenanceRecord 行表 | 详情页溯源证据区、[n] 引用 |

设计动机（教训固化）：文档骨架（条款/章节）**不是业务概念**——曾混进本体导致类/实例混乱（"托管费"既有类又有实例），已剥离到结构层；原文保真由溯源层承载（每个抽取产物可回查原文），不靠"原文当实例"。

## 一、八阶段流水线详解

### 阶段 A：解析（0 LLM，0.4s）

| 项 | 内容 |
|---|---|
| **做什么** | 代码直读原始文件：表格抽成 `{headers, rows}`，文本抽成叙述行，合并单元格回填，逐字证据打「文件[sheet]行n」指针 |
| **输入** | 原始文件（任意多文件、任意格式） |
| **输出** | 每文件 `{sheets:[{headers,rows}], narrative:[行], meta}` |
| **原理** | 按扩展名分发到格式专用解析器；PDF 做页眉/页脚/水印指纹去重（跨页重复 ≥max(3, 60%×页数) 的行剔除——说明书每页"风险提示+第N页"噪音一次清除） |
| **LLM** | 无 |
| **时长** | 0.4s（33 页 PDF）/ 0.35s（双 Excel 4400 行） |
| **长文档优化** | 页眉指纹去重使叙述行数与页数解耦；合并格回填避免行级信息丢失 |
| **边界** | 纯图片/扫描件文本层为空 → 告警（平台 OCR/VL 兜底链可接，未接） |

### 阶段 B：研判（1 次 LLM，9-12s）

| 项 | 内容 |
|---|---|
| **做什么** | 判定文档族类（本体应用/制度/叙事），决定通道权重与提示词取向 |
| **输入** | 文档样本摘要（~2KB） |
| **输出** | 族类标签 |
| **LLM** | 1 次（短卡） |
| **长文档优化** | 输入是抽样摘要，与文档体积无关 |

### 阶段 B+：结构密度路由（0 LLM，新增）

| 项 | 内容 |
|---|---|
| **做什么** | 对叙述文本算结构密度分（编号正则 `第X条/一、/1.` 行占比）→ 路由叙事抽取策略 |
| **输入** | narrative 行 |
| **输出** | density 分 + 条款数；**density≥0.25 且条款≥8 → 条款通道**，否则散文通道 |
| **原理** | 条款型文档（说明书/合同/制度）有天然编号结构——按条款边界切分可保片内零截断、片外全覆盖；全部认字符形态，零业务词 |
| **LLM** | 无（判定交给统计，路由由代码执行） |
| **时长** | <0.1s |
| **实测** | 说明书 density 0.34 → 条款通道（178 条款→26 片）；手册 0.29 → 散文通道；xlsx 纯表格无叙述 |

### 阶段 C：建模声明（≤12 次 LLM，54-76s；并行 4 路后 ~20s）

| 项 | 内容 |
|---|---|
| **做什么** | 每个表结构签名声明一次「列→谓词映射」：target_class/属性列/枚举列/规则列/矩阵声明 |
| **输入** | 每签名：表头+6 样本行（~1.1KB） |
| **输出** | table_maps（结构化映射 JSON） |
| **原理** | 签名分组：表头序列规范化后相同的表共享一次声明——声明数=结构种类数，与表数量/行数无关 |
| **LLM** | 每签名 1 次（短卡）；签名组间并行 4 路（cfg.llm_concurrency），结果按序合并保确定性 |
| **时长** | 串行 54-76s → 并行后 ~20s |
| **长文档优化** | 核心机制——输入只随结构新颖度增长；154 张同构表=7 次声明 |
| **防线** | 声明后样本行干跑，0 产出重声明（矩阵表回路） |

### 阶段 D：确定展开（0 LLM，1.1-1.2s）——伪类五道防线

| 项 | 内容 |
|---|---|
| **做什么** | 代码逐行机械展开全部数据行：属性列→实例 props、封闭枚举列→取值实体化+建边、编码形表头≥5→矩阵单元三向边、规则列→原文实例+`^[a-z_]` 命名惯例抽业务字段 |
| **输入** | sheets 数据行 + table_maps |
| **输出** | 采集卡 instances/links/relations/rules |
| **原理** | 映射由 LLM 声明一次，展开由代码确定性完成——"行→属性"的语义由声明承载，内容不过模型 |
| **LLM** | 无 |
| **时长** | 1.1-1.2s（4459 行）/ 0.00s（纯叙事文档 0 数据行） |
| **长文档优化** | 行数无限增长不影响 LLM 输入（最优性价比环节） |
| **伪类五道防线**（认形态不认业务词） | ①布尔排除（值域⊆逻辑常量表→属性）②数值/日期形态排除（45527.0 Excel 序列/纯数字→属性）③封闭性（distinct≥2 且 复用率≤0.6——每行唯一的值列拦下）④伪表头行过滤（行值与表头重合≥3 跳过 + 跨表二级表头指纹≥3 张同构表重复的行全组跳过）⑤C 声明降级（relation 路径同校验） |
| **预算闸** | 实例 1600、单表软上限 1200 |

### 阶段 E：叙事/条款抽取（LLM，并行 4 路后 200-238s；原串行 842s）

| 项 | 内容 |
|---|---|
| **做什么** | 非表格文本的语义抽取：类/实例/attributes/links/rules |
| **输入** | 散文通道：6KB 固定分片（≤40 片）；条款通道：条款边界组片（片内零截断）+ 每片头部拼「数值要素摘要」 |
| **输出** | classes/instances/attributes/links/rules/pending |
| **原理** | map-reduce；attributes 契约（新增）：主体具体取值（费率/上限/日期/基准）用 {subject,name,value} 输出并聚合到主体实例 props——属性值分流，严禁抽成实例；代码兜底：实例 label 命中属性值尾词（率/上限/日/金额/期限/费/税/基准/净值/规模）或纯数值 → 并入文档主体实例 props 不建实例 |
| **LLM** | 每片 1 次，并行 4 路（ThreadPoolExecutor，IO 计数加锁，per-future 失败跳过，按片序合并=确定性） |
| **时长** | 说明书 26 片：串行 842s → 并行 200-238s（4.2 倍） |
| **长文档优化** | ①分片=处理单元，输入限制转化为耗时而非正确性 ②片上限 40（预算闸）③条款边界分片=语义切片零截断 |
| **文档结构层** | 条款原文不进本体，进 doc_clauses（结构层）；LLM 产物 evidence 指向条款号 → 溯源层可回查 |

### 阶段 F：专家评审（2-3 次 LLM，70-90s）

| 项 | 内容 |
|---|---|
| **F 专家** | 45KB 采集卡追加式补丁（禁删改只出补丁）：挖漏规则/引用闭合/层次收编（顶类「业务对象」）+ 类别性判定纪律（仅可多实例化的概念是类） |
| **F.2 对账** | 29 句式完备性清单逐句报有据/无据/待确认（对象/约束/术语/规则/流程/权限/CRUD），同时产出 add_terms 喂术语层 |
| **F.5 消解** | 四层递进合并：①归一化同名同类自动合（props 冲突存 altN）②同名跨类编码形→多数类统一 ③跨类非编码→只进待确认绝不自动合 ④嵌入层（bge-m3，编码形豁免防短码余弦虚高） |
| **F.5 新增** | 类-实例误置降级：类名与实例名归一化相同/强包含（类"托管费"+实例"托管费"）→ 类壳删除、实例归父类/顶类、关系声明清理；过度降级保护：类下还有其它不同名实例 → 类是真的，只删同名实例 |
| **F.5 新增** | 尾词聚类收编：≥3 类共享 ≥2 字尾词 → 尾词父类（机构/资产/风险族），泛尾停用表（类型/事项/内容）防噪声 |
| **LLM** | F 专家 1 次（45KB 长卡）+ F.2 1 次 + 嵌入调用（bge-m3） |
| **时长** | 70-90s（专家 35-70s + 对账 20s + 消解 15-61s） |
| **预算闸** | 专家卡 45KB 截断（大工作簿防调用风暴） |

### 阶段 G：公理+TTL（2-3 次 LLM，31-63s）

| 项 | 内容 |
|---|---|
| **做什么** | 公理生成（domain/range/subclass/disjoint）→ 三道防线（数据反证/合法性闸/继承环）→ 过闸落图；真 SWRL 结构化；owlrl 一致性检测 |
| **输出** | TTL 文件 + 公理落位翻译到平台约定（classes[].disjoint_with/parent_classes + object_properties[].functional——前端公理卡数据源） |
| **原理** | 真 SWRL =「类断言+属性比较原子 → x∈派生类」的可执行分类规则；if_class 非类名时按实例标签→类反查兜底（认出处） |
| **LLM** | 公理生成 1 次 + 规则形式化 1 次 |
| **时长** | 31-63s（owlrl 物化 4000-8000 三元组秒级） |
| **教训** | 过闸不落图=报表装饰（公理必须写进 TTL）；函数性公理白名单制（≥3 主体且零多值违规，防 owlrl 静默 sameAs 强并） |

### 阶段 H：落平台+冒烟（0 LLM，10-17s）

| 项 | 内容 |
|---|---|
| **做什么** | 新建项目→上传解析→graph_data 写 DB（行表 entities/relations/provenance 双写）→Neo4j 批量 UNWIND→TBox 向量索引→类属性模板回填→检索冒烟两题 |
| **输出** | 三层齐备：业务本体图（画布/QA）+ 文档结构层（spec_card.doc_clauses）+ 溯源层（provenance） |
| **原理/防线** | type 边（实例→类，前端展开实例依赖）+ 类间模式边（domain→range，折叠态结构线）+ 类属性模板回填（实例 props 聚合）+ 类溯源（首次声明文档）+ source_document 落位（行表溯源映射键）+ 收编兜底（无类间边的类自动挂顶类）+ Neo4j 关系丢失自愈（落地后数关系，偏差>10% 自动重放）+ 节点 id 去重（重复 id 撞行表唯一键整体回滚）+ H 段会话重建（A-F 6 分钟空闲后旧 TCP 连接已被 keep-alive 掐死，防 Connection reset） |
| **LLM** | 无 |
| **时长** | 10-17s |

### 阶段 I：问答检索（运行时，每次提问）

| 项 | 内容 |
|---|---|
| **链路** | 提问 → 类锚定（字面子串 + TBox 向量回退 + SKOS 别名）→ 查图谱（锚定类实例清单+全图分布概览+关系边 BFS）→ 查公理（domain/range/互斥/函数性）→ 查关键词+向量切片 → 融合排序（锚定清单 0.95>公理>图边>切片，[:3]+[:2] 保额）→ LLM 接地生成 |
| **前端** | 提问 → 检索过程卡（①查图谱②查公理③查切片→综合，编号时间线可折叠，trace 事件先于答案下发）→ 答案流式（结论先行+构成式人话+口径拆解）→ 溯源引用（图节点清单重组/切片缩略+悬浮 markdown 原文表格还原） |
| **实测** | 计数题构成式（"182 = 基线 152 + 梳理 30"）；QA 模型 glm-5-3（model_config_id=12）；qwen3.5:9b 偶发空回复已弃用 |

## 二、长文档处理专题

### 输入预算体系（核心：按结构付费，不按体积付费）

| 阶段 | 输入上限 | 与文档体积关系 |
|---|---|---|
| A 解析 | 0 LLM | 无关 |
| C 声明 | 每签名 1.1KB | 只随结构种类数 |
| D 展开 | 0 LLM | 无关 |
| E 叙事 | 每片 6KB，≤40 片 | 线性（主成本） |
| F 专家 | 采集卡 45KB | 有界 |
| 证据 | 不进模型 | 指针回查 |

### 形态路由与成本

| 文档形态 | 判据 | 路径 | 成本 | 实测 |
|---|---|---|---|---|
| 表格型 | 有 sheets | 签名声明+代码展开 | 结构数×1.1KB | xlsx 124s |
| 条款型 | 密度≥0.25 | 条款通道+attributes | 片数×1 次 | pdf 708s（4.2 万字 33 页） |
| 散文 | 密度<0.25 | 分片 map-reduce | 线性 | docx 154s |

### 并行化

分片/签名组无依赖 → ThreadPool 4 路并发（cfg.llm_concurrency），并行计算按序合并=确定性；护栏=网关并发配额（对齐平台 LLM_MAX_RPM 思想）。实测 E 段 842s→200s。

### 诚实边界

纯散文超 40 片截断（预算闸取舍，宁可少抽不失控）；扫描件需 OCR/VL（脚本未接，平台有链）；信息论底线——保真抽取要求模型至少看一遍要抽的内容，条款通道通过「模板+数值槽」把"看一遍"的成本压到结构级。

## 三、核心抽取规则机制表（全部认形态/认出处，零业务词）

| # | 机制 | 判据 | 防的事故 |
|---|---|---|---|
| 1 | 签名分组声明 | 表头元组相等 | 声明数爆炸 |
| 2 | 形态驱动展开 | distinct/长度/正则 | 属性值当实体 |
| 3 | 编码形识别 | `^[A-Za-z0-9]{4,12}$` 含数字 | 短码余弦虚高误并 |
| 4 | 命名惯例 | `^[a-z_]` 才抽业务字段 | 系统编码混入 |
| 5 | 消解四层+误置降级 | 归一化/编码多数类/嵌入豁免 | 60 实例拼音误并事故 |
| 6 | 跨文档证据指针 | 逐实例 _files | 同实体两文档两份 |
| 7 | 公理三防线+落位翻译 | 反证/合法性/继承环 | 公理显示 0、sameAs 强并 |
| 8 | 真 SWRL 双路径+兜底 | dprop 注册+实例反查 | 规则形式合法但全拒 |
| 9 | SKOS 术语层 | T1-T3+异形标签 | 异形词检索不中 |
| 10 | 29 句式对账 | 固定完备性清单 | 覆盖率无法量化 |
| 11 | 预算闸 | 12000/45KB/1600/≤12 组 | 调用风暴 |
| 12 | 伪类五防线 | 布尔/数值/复用率/伪表头/声明降级 | 属性值被类化（是否必输成类） |
| 13 | 类-实例误置降级 | 归一化同名/强包含+过度降级保护 | 托管费既有类又有实例 |
| 14 | 尾词聚类 | ≥3 类共享 2 字尾词+泛尾停用 | 机构类族碎片化 |
| 15 | 文档结构层剥离 | 编号条款→doc_clauses | 文档骨架混进业务本体 |
| 16 | 属性值分流 | attributes 契约+尾词兜底 | 认购费率成散点实例 |
| 17 | 页眉指纹去重 | 跨页重复≥60%×页数 | 说明书噪音污染全部叙述 |
| 18 | type/schema 边+类属性模板+类溯源 | class_label 匹配/实例 props 聚合/首申文档 | 前端实例展开失败/折叠态孤点/公理显示 0 |

## 七、风险与边界
