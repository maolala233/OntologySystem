## 一、系统概述

OntologySystem 是一个**面向非专业用户的知识图谱构建与管理平台**：把文档（合同、公告、研报、制度文件等）上传进来，系统自动完成"解析 → 知识抽取 → 本体 Schema 构建 → 图谱落库"，并提供审核、发布、问答、报告、开放接口（MCP）等配套能力。

### 1.1 核心概念

| 概念 | 说明 |
| --- | --- |
| **知识域** | 知识的领域分类（如"金融""医疗"），建项目时选择，供资产归集与检索使用 |
| **项目** | 知识构建的基本单位，包含文档集、本体 Schema、图谱、版本历史；数据按项目隔离 |
| **本体 Schema** | 实体类型 / 关系类型 / 属性的定义，是图谱的"模板" |
| **实体 / 关系** | 从文档中抽出的节点与边，构成知识图谱 |
| **版本** | 图谱的快照。抽取结果合入会生成版本；手动编辑实例也会留痕成版本 |
| **审核流** | 抽取结果（实例）须审核通过才允许合入图谱 |
| **发布** | 项目发布后进入资产中心公共区，供全平台用户浏览复用 |
| **模块授权** | 功能开关：问答 / 报告 / PPT / MCP / 审核等模块可按用户逐一授权 |

> 📷 截图位 1-1：系统全貌 —— 建议截"图谱页 + 左侧导航"全景图

### 1.2 一个典型使用旅程

```
建项目 → 上传文档 → 自动解析 → LLM 抽取 → 审核通过 → 合入图谱 → 发布到资产中心
                                                              ↓
                                        本体问答 / 报告 PPT / MCP 对外服务
```

## 二、快速上手：十分钟完成知识抽取闭环

本节带新用户走一遍最小闭环。各步骤的详细说明见后续章节。

**第 1 步：登录**。浏览器打开系统地址，输入用户名密码（账号由管理员创建，见第三章）。

> 📷 截图位 2-1：登录页

**第 2 步：新建项目**。进入"我的项目"→ 点击"新建项目"→ 填写项目名称、选择知识域。

> 📷 截图位 2-2：新建项目弹窗

**第 3 步：上传文档**。进入项目 → "文档"页签 → 上传 PDF / Word / Markdown 等文件，系统自动开始解析（进度条实时可见）。

> 📷 截图位 2-3：文档上传与解析进度

**第 4 步：启动抽取**。解析完成后，对文档启动"知识抽取"，抽取完成后可查看抽出的实体和关系。

> 📷 截图位 2-4：抽取结果页

**第 5 步：审核合入**。抽取结果进入"审核工作台"，审核通过后合入图谱，可在"图谱"页签查看可视化知识图谱。

> 📷 截图位 2-5：图谱可视化页面

**第 6 步：提问验证**。进入"工具 → 本体问答"，用自然语言提问，系统基于刚构建的图谱回答并附溯源出处。

> 📷 截图位 2-6：本体问答带 [n] 溯源

## 三、登录与账号

### 3.1 登录

- 系统地址由管理员提供（本地部署默认 `http://localhost:5173` 或 `http://<服务器IP>:3080`）。
- 输入用户名与密码；勾选"记住我"可延长登录态。
- 登录态过期时页面会自动跳回登录页，重新登录即可。

- 开放注册时可在登录页自助注册（用户名 + 密码）；注册后的用户默认按系统"默认开通模块"获得功能。
- 密码遗忘请联系管理员在"用户管理"中重置。
- 用户本人可在右上角头像菜单中"修改密码"。

> 📷 截图位 3-2：头像下拉菜单（修改密码 / 设置 / 退出登录）

## 五、我的项目：本体构建全流程

"我的项目"列出你有权限的项目（自己创建的 + 被加为成员的），是使用频率最高的页面。

> 📷 截图位 5-1：我的项目列表页

### 5.1 创建与管理项目

1. 点击"新建项目"，填写：项目名称（必填）、项目描述、所属知识域；
2. 创建后项目出现在列表中，点击进入项目工作区；
3. 项目工作区包含四个页签：**文档、Schema、图谱、时间线**。

> 📷 截图位 5-2：项目工作区四页签总览

**项目成员与角色**：项目所有者（owner）可在成员管理中添加协作者，协作者角色分 owner / editor / viewer 三级：

- **owner**：全部权限，含删除项目、管理成员；
- **editor**：可上传文档、编辑 Schema、编辑图谱实例；
- **viewer**：只读。

> 📷 截图位 5-3：项目成员管理

### 5.2 文档管理（文档页签）

**支持的格式**：PDF（含扫描件）、Word（docx）、Markdown、TXT 等。

上传与解析：

1. 点击"上传"，可多选文件批量上传（单文件默认上限 100MB）；
2. 上传后自动排队解析：普通文本走快速通道；PDF 自动判断——文本层完整的直接结构化解析，扫描件自动启用 OCR；
3. 列表中实时显示每个文档的解析状态（排队中 / 解析中 / 成功 / 失败）、页数、切片数；
4. 解析失败的文档可查看失败原因并重试。

> 📷 截图位 5-4：文档列表（含解析状态列）

**切片参数（进阶）**：默认按 2000 字符切块；如需控制粒度，可关闭"自动解析"，在手动解析时指定 chunk_size 等参数。

### 5.3 知识抽取

解析完成后，选中文档启动"抽取"：

1. 抽取任务提交到后台队列，进度实时刷新（抽取中 / 已完成 / 失败）；
2. 抽取结果 = **实体（节点）+ 关系（边）**，每条结果都带原文出处（可点开查看命中的原文段落）；
3. 抽取结果不直接进图谱，而是进入待审核池（见第六章）。

> 📷 截图位 5-5：抽取结果列表（含出处展开）

### 5.4 Schema 编辑（Schema 页签）

本体 Schema 定义"有哪些实体类型、哪些关系类型、各自有什么属性"：

- 系统支持从文档自动归纳生成 Schema 草稿（LLM 辅助），也可手工创建；
- 支持导入 / 导出 TTL（本体的标准格式），便于与外部本体工具互通；
- 编辑 Schema 不影响已入库的图谱数据，但影响后续抽取的归类。

> 📷 截图位 5-6：Schema 编辑页（实体类型 / 关系类型两个列表）

### 5.5 图谱浏览与手动编辑（图谱页签）

图谱页是可视化核心：

- **画布交互**：拖拽平移、滚轮缩放、点选节点；选中节点/边后右侧显示详情（属性、出入边、来源文档）；
- **检索定位**：按实体名称搜索，支持按实体类型过滤；节点按类型着色（悬浮显示类型气泡说明）；
- **手动编辑**（R13）：可直接在图上手动新增/修改/删除实例（节点与边）；每次手动编辑都会自动生成版本留痕，可在时间线中追溯与回滚；
- **查询**：内置图查询（按起点实体展开邻居、按条件筛选子图），结果同样以画布呈现。

> 📷 截图位 5-7：图谱画布（选中一个节点展示右侧详情栏）
> 📷 截图位 5-8：手动编辑实例的弹窗

### 5.6 版本与时间线（时间线页签）

- 图谱的每次批量合入（抽取结果审核通过）和每次手动编辑都会生成一个**版本**；
- 时间线页按时间倒序展示版本列表：版本号、触发方式（抽取合入 / 手动编辑 / 发布）、操作者、变更摘要；
- 支持查看任意两个版本之间的差异，并可回滚到历史版本。

> 📷 截图位 5-9：时间线版本列表
> 📷 截图位 5-10：版本差异对比视图

### 5.7 发布

项目构建完成后，可申请**发布**：

1. owner 点击"发布"，项目进入发布审核（若平台未开启审核则直接生效）；
2. 发布成功后项目状态变为"已发布"，其图谱进入**资产中心**公共区，全平台可浏览；
3. 已发布项目处于只读状态，须"取消发布"才能继续编辑（会生成新版本分支）。

> 📷 截图位 5-11：项目发布确认弹窗

## 六、审核工作台

抽取结果的质量把关环节。开通了 review 模块的用户可见此菜单。

### 6.1 待审列表

- 按项目 / 文档 / 抽取批次聚合展示待审核的实体与关系；
- 每条记录显示：实体或关系的类型、名称/主谓宾、置信度、来源文档与原文片段。

> 📷 截图位 6-1：审核工作台待审列表

### 6.2 审核操作

- **通过 / 驳回**：逐条审核，也可批量通过；驳回须填写原因；
- **修正后通过**：审核员可直接修改实体名称、类型或属性值再通过；
- **合入**：一批审核通过后执行"合入"，数据写入图谱并生成新版本；
- 合入后可在时间线中追溯本次合入的版本号。

> 📷 截图位 6-2：审核详情（原文对照 + 通过/驳回按钮）

## 八、本体问答

基于 GraphRAG 的自然语言问答：问题 → 图谱+向量检索 → LLM 生成带溯源的回答。

### 8.1 基本用法

1. 进入"工具 → 本体问答"；
2. 选择提问范围（我的项目 / 已发布资产）；
3. 输入自然语言问题，如："这个产品的投资范围是什么？"；
4. 回答以 Markdown 呈现，关键结论后带 **[n] 角标**，点击角标可展开命中原文与出处文档，用于人工核对。

> 📷 截图位 8-1：问答页（问题 + 带 [n] 角标的回答）
> 📷 截图位 8-2：点击角标展开的溯源原文

### 8.2 提问技巧

- 问题尽量落在已构建图谱的范围内，命中质量与图谱覆盖度直接相关；
- 支持"逻辑题"：如涉及多条规则/条件的推理，系统会检索相关实体与关系后作答；
- 回答末尾列出的 sources 是检索命中的原文段落，**结论务必对照原文使用**；
- 历史问答自动保留，可回看与追问。

> 📷 截图位 8-3：历史问答侧栏

## 十、MCP 服务

MCP（Model Context Protocol）控制台把平台图谱能力**开放给外部 AI 客户端**（Cursor、Claude、自研 Agent 等）调用。开通 mcp 模块的用户可见此菜单。

### 10.1 三步接入

1. **签发令牌**：左栏点"签发"创建 `sk-mcp-` 令牌——绑定项目、勾选是否允许写入；**明文只展示一次**，当场复制保存；
2. **确认端点**：默认按浏览器地址自动推导（如 `http://<服务器IP>:3001/mcp`）；容器化/反向代理部署可在输入框修改为实际可达地址（如 `https://<域名>/mcp`），修改后自动记住；
3. **配置客户端**：把端点 + 令牌按"接入说明"页签的示例配进 MCP 客户端（curl / Python SDK / Cursor / Claude Code 均有现成模板）。

> 📷 截图位 10-1：MCP 控制台左栏（端点 + 令牌选择 + 连接按钮）
> 📷 截图位 10-2：签发令牌弹窗（含明文仅此一次提示）

### 10.2 控制台功能

- **连接调试**：选择令牌点"连接"，成功后列出该令牌可见的工具与资源；
- **工具调用**：左侧选中工具 → 右侧按 Schema 填参 → "运行工具"，结果以 JSON 树展示；底部保留最近 50 次调用历史（可展开请求/响应回放）；
- **资源浏览**：List Resources 列出令牌可见的图谱资源（实体详情等）并可直接读取；
- **Ping**：一键检测端点连通性与延迟。

> 📷 截图位 10-3：工具调用与 JSON 结果树
> 📷 截图位 10-4：调用历史展开回放

### 10.3 权限与安全约定

- **普通用户**：只能管理自己名下的令牌；令牌绑定的项目须是自己有成员身份的项目；
- **管理员**：可为平台任意用户代签令牌；
- 令牌与单项目绑定（数据隔离），只读令牌不暴露写入类工具；撤销后立即失效；
- 限流：读类 60 次/分钟、写类 20 次/分钟（每令牌）；
- 平台只存令牌的 SHA-256 哈希，明文丢失无法找回，只能撤销重签。

### 10.4 对外暴露的典型工具

| 工具 | 用途 |
| --- | --- |
| `search_entities` | 按关键词检索实体 |
| `get_entity` / `get_neighbors` | 实体详情 / 一跳邻居 |
| `query_graph` | 条件子图查询 |
| `get_ontology_schema` | 获取项目本体 Schema |
| `ask` | GraphRAG 问答（与"本体问答"同链路） |
| `export_graph` | 导出图谱 |
| `add_entity` / `add_relationship` | 写入（需可写令牌） |

### 11.2 用户管理

> 📷 截图位 11-2：用户管理列表

### 11.3 模块授权

按用户逐一配置功能模块开关（问答、报告、PPT、MCP、审核等）：

- 未在矩阵中配置的用户按模块的"默认开通"兜底；
- 修改即时生效，用户刷新页面后菜单随之变化。

### 11.4 模型配置

配置平台用到的模型服务：

- **对话模型（LLM）**：抽取、问答、报告生成共用；可配多套并指定启用集，支持按用途（抽取/问答）切换主备；
- **Embedding 模型**：向量检索用，注意维度需与向量库一致（当前环境为 bge-m3 / 1024 维）；
- 连接参数：Base URL、API Key、模型名，保存后可"测试连通"；
- 模型速度因远端服务而异，批量抽取任务请合理安排窗口。

## 十二、权限体系说明

### 12.1 三层权限模型

系统权限由三层叠加判定（任一层不通过即拒绝）：

```
第 1 层 平台角色        admin（全模块直通）/ user（按授权）
第 2 层 模块授权        user 逐一配置功能模块开关（显式拒绝 > 显式允许 > 默认开通）
第 3 层 项目角色        owner > editor > viewer（决定对某个项目的读写级）
```

### 12.2 常见场景对照

| 场景 | 判定 |
| --- | --- |
| 普通用户看不到"MCP 服务"菜单 | 该用户未开通 mcp 模块，联系管理员在模块授权中开通 |
| 用户能看到项目但无法编辑 | 项目角色为 viewer，需 owner 提升为 editor |
| 已发布项目不能编辑 | 发布态只读是产品设计；取消发布后恢复编辑 |
| 普通管理员 vs 超级管理员 | 平台主账号（用户名 admin）可跨租户访问所有项目；其余 admin 只在模块与管理后台直通，项目访问与普通用户一致 |

### 12.3 数据隔离约定

- 项目数据（文档、图谱、令牌）按项目隔离，非成员不可见；
- MCP 令牌绑定单项目，跨项目数据不可通过单令牌访问；
- 审计日志记录令牌签发/撤销、用户授权变更、图谱手动编辑等敏感操作。

## 十三、常见问题 FAQ

**Q1：文档解析一直"排队中"？**
解析任务由后台队列处理，高峰期会排队。长时间（>10 分钟）无进展请联系管理员检查 worker 进程。

**Q2：抽取结果为空或质量差？**
① 检查文档是否解析成功（有切片数才有抽取基础）；② 确认模型配置的对话模型可用（管理员在模型配置里"测试连通"）；③ 扫描件确认走的是 OCR 通道。

**Q3：问答回答说"未找到相关信息"？**
问题涉及的实体可能未被抽取入库，或未合入图谱。先在图谱页检索相关实体确认覆盖，再重试提问。

**Q4：上传扫描版 PDF 识别效果差？**
系统自动走 OCR（RapidOCR 中文模型），清晰度是主要影响因素；300dpi 以上的扫描件效果最佳。

**Q5：MCP 连接失败（401）？**
① 令牌是否选择正确、是否已被撤销；② 端点是否可达——容器化/反代部署记得把端点改成实际地址；③ 除 initialize 外所有调用都要带令牌。

**Q6：MCP 明文令牌丢了？**
无法找回（平台只存哈希）。在控制台对旧令牌"撤销"后重新签发即可。

**Q7：修改了模型配置为什么没生效？**
保存后新任务即用新配置；正在执行中的任务不受影响。必要时重启后端服务。

**Q8：页面白屏或"项目加载失败"？**
多为登录态过期：刷新页面重新登录；仍不行则按 F12 查看控制台报错并反馈给管理员。
